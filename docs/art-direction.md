# DIY Video Deck — Website Art Direction Specification

## Project purpose

Create an online website to present and document a DIY retro-futurist video deck project.

The website must serve both as:

- a presentation of the finished object;
- a journal of the technical and creative process;
- a space to explain motivations, design choices, references, constraints, iterations, and experiments;
- a visual archive of the project through photos, diagrams, UI captures, sketches, technical notes, and build logs.

The site should feel **light, clear, editorial, and image-first**, while carrying subtle references to vintage Sony Hi-Fi, analog television, cassette futurism, and late-70s / early-80s industrial design.

The goal is **not** to make a kitschy “retro website.”
The site should feel contemporary, with vintage language appearing mainly through details.

---

# Core visual principles

The general balance should be:

```text
80–90% contemporary editorial website
10–20% vintage / analog / Sony-inspired detail
```

The vintage references should come through:

- technical labels;
- tuner scales;
- thin rules;
- small instrument-inspired details;
- amber and red indicators;
- analog-TV terminology;
- period-inspired typography;
- service-manual annotations;
- restrained animation effects.

Avoid heavy skeuomorphism.
Avoid permanently noisy CRT backgrounds.
Avoid excessive glitch effects.
Avoid making the interface look like a synthesizer plugin.

Readability and image presentation are the priority.

# Art Direction 01 — SONY SERVICE MANUAL / INDUSTRIAL EDITORIAL

## Concept

A very clean, almost archival editorial direction inspired by:

- Sony catalogs from the late 1970s;
- service manuals;
- industrial design documentation;
- contemporary design magazines.

This is probably the strongest base direction for the project.

## Visual language

Use:

- warm off-white or very light neutral background;
- large amounts of whitespace;
- oversized project photography;
- fine black technical rules;
- small technical annotations;
- reference codes;
- figure numbers;
- component names;
- channel/frequency metadata;
- understated accent color.

## Suggested palette

```text
Background: #F2F0E9 or warm off-white
Primary text: charcoal / near black
Secondary text: aluminum gray
Accent 01: Sony-style red
Accent 02: amber/orange for interactive states
```

## Typography direction

Main typeface:

- Helvetica / Helvetica Neue style;
- Univers style;
- neutral grotesk.

Secondary technical typeface:

- monospace;
- condensed sans-serif;
- technical annotation style.

## Example image caption

```text
FIG. 04 / FRONT PANEL ASSEMBLY
VIDEO DECK PROTOTYPE — REV. B
UHF DISPLAY / CRT SIMULATION
```

## Suggested navigation

```text
PROJECT   OBJECT   PROCESS   TECHNICAL   JOURNAL   ABOUT
```

## Editorial behavior

Posts should feel more like **illustrated essays** than conventional blog posts.

Use large images, short captions, technical diagrams, pull-quotes, specifications, and narrative text.

## Strengths

- very readable;
- timeless;
- ideal for long-form technical posts;
- strong image presentation;
- subtle vintage identity;
- easy to maintain visually over time.

# Art Direction 02 — BLACK GLASS / SONY RECEIVER

## Concept

A darker direction inspired directly by late-70s Sony receivers and Hi-Fi front panels:

- black glass;
- white silk-screen markings;
- analog meters;
- tuner graduations;
- illuminated amber cursors;
- red indicator LEDs.

The overall site should still remain restrained.

## Visual language

Main elements:

- deep black background;
- studio-lit object photography;
- thin white typography;
- tuner scales;
- instrument labels;
- meter-inspired metadata;
- amber cursor accents;
- occasional red indicators.

## Example tuner graphic

```text
VHF-L     2      3      4
VHF-H     5   6   7   8   9   10
UHF      21  25  30  35  40  45  50
MHz      470 500 550 600 650 700 750
```

## Example category treatment

```text
● DESIGN
○ ELECTRONICS
○ SOFTWARE
```

## Example instrumentation detail

```text
SIGNAL          TV TUNING
```

These motifs should appear only as interface accents, separators, or small informational modules.

## Important restraint

Do not turn the whole website into a fake receiver front panel.

The reference should appear in:

- header areas;
- metadata;
- transitions;
- section separators;
- hover states;
- navigation details.

The reading areas themselves should remain simple.

## Strengths

- very recognizable Sony / Hi-Fi identity;
- strong atmosphere;
- excellent for hero images and object presentation;
- easy to connect to the physical deck aesthetic.

## Risk

If overused, it may become too “synth plugin” or “retro UI.”

# Art Direction 03 — CASSETTE FUTURISM / TECHNICAL MAGAZINE

## Concept

An editorial direction inspired by an early-1980s magazine imagining the future.

Think:

- large photography;
- cream backgrounds;
- black typography;
- gray-blue and orange accents;
- rational grids;
- technical diagrams;
- experimental editorial layouts.

## Suggested section numbering

```text
01
THE OBJECT

02
WHY ANALOG VIDEO?

03
SIGNAL PATH

04
BUILD LOG
```

## Image annotation style

```text
A — MOTOROLA XT1092 OLED DISPLAY
B — RASPBERRY PI VIDEO SOURCE
C — UHF MODULATOR
D — CUSTOM FRONT PANEL
```

## Content suitability

This direction is especially useful for combining:

- prototype photography;
- technical plans;
- sketches;
- UI screenshots;
- electronic diagrams;
- source-code snippets;
- component close-ups.

## Design principle

The vintage character should come primarily from **layout and typography**, not artificial CRT effects.

## Strengths

- visually rich;
- strong storytelling potential;
- very good for explaining process and iteration;
- distinctive without becoming overly nostalgic.

# Art Direction 04 — RESTOMOD WORKSHOP

## Concept

This direction focuses on the project as an **electronic restomod**.

Visual inspiration comes from:

- premium automotive restomod websites;
- industrial workshops;
- material studies;
- assembly documentation;
- mechanical detail photography.

## Visual language

Use:

- light neutral backgrounds;
- brushed aluminum references;
- high-quality detail photography;
- macro shots;
- exploded views;
- original vs modified comparisons;
- component notes.

## Example comparison block

```text
ORIGINAL
Sony cassette deck chassis
1979

MODIFIED
OLED display
Raspberry Pi video source
Custom RGB indicator
UHF output
```

## Example design decision block

```text
KEEP
Mechanical controls
Front panel geometry
Period typography

REPLACE
Tape transport
Counter mechanism
Internal electronics

ADD
Digital video playback
Remote management
Analog RF output
```

## Strengths

- clearly communicates the “restomod” philosophy;
- good for explaining design choices;
- strong material and object focus;
- less dependent on literal retro styling.

## Character

This direction feels more premium and industrial than nostalgic.

# Art Direction 05 — ANALOG TV / RF LAB

## Concept

A direction based specifically on analog television and RF tuning.

Visual references:

- VHF / UHF bands;
- channel numbers;
- tuning scales;
- signal meters;
- television test patterns;
- sync loss;
- scanlines;
- RF measurements;
- analog broadcast terminology.

## Example metadata

```text
CHANNEL 21
471.25 MHz

SIGNAL 4.2
TUNING +0.03

625 LINES
UHF BAND IV/V
```

## Possible interactions

Small interaction ideas:

- brief static flash on section change;
- tiny sync-loss transition;
- channel-lock state on hover;
- signal meter fluctuations;
- tuner cursor movement;
- CRT line animation at page load.

## CRT startup motif

A particularly strong signature interaction:

```text
black screen
→ thin white horizontal line appears
→ line expands briefly
→ page content is revealed
```

This should be short, elegant, and optional rather than intrusive.

## Important restraint

Never use static noise as a permanent page background.

Glitch and analog-video effects should act as **punctuation**, not decoration everywhere.

## Strengths

- directly tied to the technical concept of the project;
- highly distinctive;
- ideal for micro-interactions;
- supports the project’s analog video narrative.

# Recommended combined direction

The recommended final visual language is a combination of:

```text
01 — Sony Service Manual / Industrial Editorial
+
02 — Black Glass / Sony Receiver
+
05 — Analog TV / RF Lab
```

The **base layout** should come from Art Direction 01.

This guarantees:

- excellent readability;
- strong visual hierarchy;
- large image presentation;
- long-form editorial comfort;
- future-proof design.

Then introduce Hi-Fi details from Art Direction 02:

```text
Helvetica / Univers style
thin technical rules
black glass panels
amber cursor
red indicators
SIGNAL / TV TUNING
UHF / VHF scales
```

Finally, add very subtle analog-TV interactions from Art Direction 05:

```text
CRT power-on line
brief static transition
channel lock
signal fluctuation
frequency numbers
```

The combination can be described as:

# SONY RESTOMOD / ANALOG VIDEO LAB

# Typography recommendations

Preferred visual family:

- Helvetica Neue;
- Univers;
- Neue Haas Grotesk style;
- neutral Swiss grotesk.

If licensing or webfont availability is an issue, consider:

- Archivo;
- Archivo Narrow;
- IBM Plex Sans;
- IBM Plex Mono for technical metadata.

Recommended combination:

```text
Main editorial text:
neutral grotesk

Technical annotations:
IBM Plex Mono or condensed grotesk
```

Avoid overly geometric contemporary sans-serifs if they make the site feel too modern or startup-like.

# Motion and interaction principles

Animations should be:

- short;
- restrained;
- subtle;
- functionally connected to the project concept.

Recommended ideas:

### CRT reveal

```text
black
→ white horizontal line
→ content reveal
```

### Tuner cursor

A small amber cursor can move along a scale during navigation or scroll.

### Signal meter

A subtle animated SIGNAL meter may react to hover or loading states.

### TV tuning meter

Use only as a minor decorative indicator.

### Static transition

A very brief analog-noise flash may be used between certain content states.

Avoid long or aggressive glitch effects.

---

# Things to avoid

Avoid:

- permanent CRT scanlines over the whole site;
- constant VHS noise;
- excessive neon;
- cyberpunk styling;
- fake terminal UI everywhere;
- excessive gradients;
- fake 3D knobs and switches;
- too many animated meters;
- unreadable condensed typography for body text;
- decorative clutter around images;
- overuse of black backgrounds;
- excessive nostalgia or parody.

The project should feel like a serious contemporary design object informed by vintage electronics, not a themed retro website.
